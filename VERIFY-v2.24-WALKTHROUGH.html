7Sab modals/pages ka audit — kya nikla

“Identify, analyze, debug” ka natija — ye asli bugs thay jo aap ko dikh rahe thay, aur inki root fix:

  1. Search-type field ka code hi maujood nahi tha — isi wajah se Demand ke fields bhare hue bhi “kaam nahi karte” lagte thay. Ab asli async search hai.
  2. Dropdown ban kar DOM mein lagta hi nahi tha — results root mein append nahi hote thay, is liye kuch nazar nahi aata tha.
  3. PO screen par purane helper delete ho gaye thay — “Code nahi mila” ka silent error.
  4. Stock Issue modal slow API par khulta hi nahi tha — ab modal pehle, data baad mein.
  5. Screen buttons event object title mein le rahe thay — title “PO undefined” ban jata tha.
  6. Boot ka Esc handler null par crash — “close kaam nahi karta” ki asli jarh.
  7. Drawer mein Esc ka koi support nahi tha — ab do-step Esc sab jagah.

Har fix shared logic mein hua (page-specific patch nahi) — is liye PO/GRN/PWA/Inventory/Returns sab ko ek saath faida hua.
