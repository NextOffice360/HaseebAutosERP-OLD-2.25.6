# Haseeb Autos — Live Camera Scanner (static, self-hostable)

One-page QR/barcode scanner that runs OUTSIDE the Apps Script sandbox so the
phone camera actually works. No build, no npm, no server logic — two files:

```
index.html                  the scanner (open it directly to test)
vendor/html5-qrcode.min.js  html5-qrcode v2.3.8 (MIT), pinned fallback decoder
```

## 3-minute deploy on GitHub Pages (free)

1. github.com → **New repository** → name `haseeb-autos-scanner` → **Public** → Create.
2. **Add file → Upload file** → upload `index.html`. **Add file → Upload files** → upload
   `vendor/html5-qrcode.min.js` (keep the `vendor/` folder — drag the folder in). **Commit**.
3. **Settings → Pages** → Source: **Deploy from a branch** → branch `main`, folder `/ (root)` → **Save**.
4. Your URL (1–2 minutes): `https://<username>.github.io/haseeb-autos-scanner/`
5. In the ERP: **Settings ▸ Mobile apps (PWA) ▸ scanner.liveUrl** → paste that URL → **Save**.
   Done — POS “📷 Scan” now opens a real camera page on desktop and phones.

Any other HTTPS host works the same way: upload the folder anywhere that serves
`https://` (your own domain, Firebase Hosting, Netlify, Cloudflare Pages).
HTTPS is mandatory — browsers only allow cameras on secure origins.

## Verify

- Open the Pages URL on your phone → “Start camera” → Allow → point at a QR → it shows
  the value (standalone mode: Copy button).
- From the ERP: Settings ▸ scan from POS → popup opens → scan → popup closes and the
  item lands in the cart.

## Security notes

- The scanner posts the value ONLY to `window.opener`, ONLY when the `ret` parameter is
  `https://script.google.com` or a `https://*.googleusercontent.com` Apps Script panel origin.
- A per-session nonce (generated by the ERP, echoed back) prevents other windows from
  injecting results.
- No frames, no photos, no text ever leave the device — nothing is uploaded, no analytics,
  no CDN. Vendor library is bundled (pinned copy, SHA-256 in the guide), not fetched at runtime.
