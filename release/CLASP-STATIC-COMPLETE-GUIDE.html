0. CLASP kya hai — aur humein kyun chahiye?

🧠 Asaan misaal

Sochiye aap ke paas ek dukaan ka software hai (Haseeb Autos) — wo 71 files ki shakal mein aap ke computer par pada hai.

Ab wo Google ke server par chahni hain, taake mobile aur computer dono se internet par khul sakein.

CheezMisaal
Aap ke computer ka folderAap ka ghar (samaan pada hai)
Google Apps ScriptAap ki dukaan (server par)
CLASPTruck — ghar se dukaan tak samaan le jane wala 🚚
DeploymentDukaan ka darwaza kholna — log andar aa sakein 🚪

CLASP ke bagair kya karna parhta?

Har file ko Google ki website par ek ek kar ke copy-paste karna — 71 files! Ek ghalti to poora software kharaab.

CLASP se kya hota hai?

Aik command: clasp push — sari 71 files 30 second mein Google par.

✅ 3 bade stage
  1. Install — Node.js + CLASP (sirf ek dafa)
  2. Push — code Google par bhejna
  3. Deploy — darwaza kholna (URL lena)

16. Undo / Recovery — agar kuch bigar jaye REQUIRED

🛡 Pehle bachao (2 minute ka kaam)

In dono mein se koi aik kar lein — aage chal kar bohot kaam aayega:

  1. Zip bana lein: apps-script folder par Right-click → Send to → Compressed (zipped) folder
  2. Ya copy bana lein: folder ko copy kar ke apps-script-BACKUP

Haalat 1 — Push ke baad app kharaab ho gayi

HAL

Google par versions ki history hoti hai — purana version wapas la sakte hain.

KAise
  1. Deploy → Manage deployments → ✏ Edit
  2. Version dropdown mein purana number chunein (masalan 2)
  3. Deploy
  4. App wapas purani (chalti hui) halat mein aa jaye gi ✅

Haalat 2 — Local files mit gayin (pull ne overwrite kiya)

HAL
  1. Agar backup banaya tha → apps-script-BACKUP se wapas copy karein ✅
  2. Backup nahi? → clasp clone <Script ID> naye khali folder mein (Google se wapas mil jayega) ✅

Haalat 3 — Ghalat Script ID se ghalat project mein push ho gaya

HAL
  1. Ghabrayein nahi — aap ki local files mehfooz hain (kuch nahi mita)
  2. .clasp.json mein sahi Script ID dal dein
  3. Dobara clasp push

Haalat 4 — Login kharaab / dobara shuru karna hai

TYPE
clasp logout clasp login
YOU SEE
Logged out. 🔑 Authorize clasp by visiting this url: …
NEXT

Browser mein Allow → wapas Enter

⚠ Ek hi cheez jo wapas nahi aa sakti

Google Sheets ka data (aap ki asli sales/stock). Is liye kabhi kabhi File → Download → CSV se backup bana lein.
