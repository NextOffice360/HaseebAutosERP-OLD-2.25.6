clasp se direct push — copy-paste se chhutkara

Windows 10 · bilkul shuru se · har click likha hua. Ek dafa setup ho jaye to har future fix sirf 2 command se live ho jayega.

clasp kya hai? Google ka apna command-line tool. Ye aap ke computer ki apps-script/ folder ki files seedha Google par upload kar deta hai — file kholna, code paste karna, save dabana… kuch nahi karna parta.

Hissa 1 — Node.js install karein (ek dafa)

  1. Browser mein kholein: https://nodejs.org
  2. LTS wala button dabayein (green) — file download hogi
  3. Download hui file par double click → Next → Next → Install (sab default rakhein)
  4. Install ke baad Start menu se Command Prompt kholein (search: cmd)
  5. Check karein — ye likh kar Enter dabayein: 
    node -v
    Agar v20.x.x jaisa number aaye to ✔ Node.js lag gaya.

Hissa 2 — clasp install karein (ek dafa)

Command Prompt mein ye line likh kar Enter dabayein:

npm install -g @google/clasp

Check:

clasp --version

Version number aaye to ✔ tayyar hai.

Hissa 3 — Google account se login (ek dafa)

clasp login
  1. Browser khud khul jayega
  2. Apna wahi Google account chunein jis mein Haseeb Autos ka Apps Script project hai
  3. Allow dabaayein
  4. Command Prompt mein likha aayega: Authorization successful.
Agar browser na khule ya error aaye to ye command azmaayein — ye ek code deta hai jo aap khud browser mein paste karte hain: 
clasp login --no-localhost

Hissa 4 — apna Script ID nikalein (ek dafa)

  1. Browser mein script.google.com kholein → apna Haseeb Autos project kholein
  2. Address bar ka URL kuch aisa hoga: 
    https://script.google.com/home/projects/1AbCdEf…lamba/edit
  3. /projects/ aur /edit ke darmiyani lambe hisse ko copy karein — wahi Script ID hai

Hissa 5 — project ko jodna (ek dafa)

Command Prompt mein project folder mein jayein (jahan zip se files nikali thin):

cd C:\Users\AapKaNaam\Downloads\haseeb-autos
Asaan tareeqa: File Explorer mein us folder par jayein jahan apps-script folder hai, address bar mein cmd likh kar Enter dabayein — Command Prompt usi folder mein khul jayega.

Zip ke sath clasp.template.json file aati hai. Usay .clasp.json ke naam se copy karein (Windows Explorer mein file ka naam badal dein), phir Notepad se khol kar scriptId ki jagah apna Script ID paste karein:

{
  "scriptId": "1AbCdEf…(aap ka script id)",
  "rootDir": "apps-script",
  "projectId": "haseeb-autos-erp"
}
rootDir zaroori hai. Ye batata hai ke code apps-script folder mein hai — warna clasp poori zip (tools, demo, reports) upload karne lagega.

Check karein ke clasp project se baat kar pa raha hai:

clasp setting rootDir apps-script
clasp list

clasp list aap ke projects ki list dikhaye to ✔ jud gaya.

Hissa 6 — rozana ka kaam: sirf 2 command

1. Code Google par bhejein

clasp push

Poochay ga Manifest file has been updated… waghera — y dabaayein. Har file upload hote hue dikhegi:

└── Code.gs
└── AI.gs
└── App_Core.html
…
Pushed N files.

2. Web app ko update karein

clasp deploy

Ye nayi version banata hai aur deploy kar deta hai. Output mein Web app URL dikhega.

Bas itna hi. Ab koi copy-paste nahi: clasp push → clasp deploy → phone par refresh.

Purani deployment update karni ho (URL na badle)

clasp deploy har dafa naya URL banata hai. Agar aap ko wahi purana URL rakhna hai (jo aap ne phone par save kiya hai) to pehle deployment ID nikalein:

clasp deployments

List mein se apni web app ka Deployment ID copy karein, phir:

clasp deploy -d "US-DEPLOYMENT-ID-YAHAN"

Is se wahi URL nayi version par chala jayega — dobara kisi ko link nahi bhejna parega.

Hissa 7 — kaam asaan karne wale commands

CommandKya karta hai
clasp pushComputer ka code Google par bhejta hai
clasp push -wWatch mode — file save karte hi khud push ho jati hai (Ctrl+C se band)
clasp deployNayi version + nayi deployment (naya URL)
clasp deploy -d "ID"Purani deployment update (URL wahi rehta hai)
clasp deploymentsSab deployments ki list + IDs
clasp pullGoogle se code wapas computer par laata hai (⚠ apni local files overwrite ho jayengi)
clasp openProject browser mein khol deta hai
clasp logsServer ke logs Command Prompt mein — Execution log ka alternative
clasp logoutAccount se sign out

Hissa 8 — Deploy ke baad access setting

Zaroori: clasp se deploy karne ke baad Who has access check karein. Anyone na chunne par mobile par "Sorry, unable to open the file at present" aata hai (Google ka sign-in redirect bug).

Deploy ▸ Manage deployments ▸ ✏ Edit ▸ Who has access: Anyone ▸ Deploy

Hissa 9 — Aam masle aur un ka hal

Error / maslaHal
clasp : The term 'clasp' is not recognized Command Prompt band kar ke dobara kholein (install ke baad path update hota hai). Phir bhi na ho to npm install -g @google/clasp dobara chalayein.
Script ID not found / Could not find .clasp.json Aap sahi folder mein nahi hain. dir likh kar dekhein ke .clasp.json aur apps-script folder nazar aa raha hai.
You are not logged in clasp login chalayein.
Push ho gaya magar app mein tabdeeli nahi aayi Push sirf code bhejta hai — deploy zaroori hai: clasp deploy -d "ID". Phir browser mein Ctrl+Shift+R (hard refresh).
Manifest file has been updated. Do you want to continue? y dabaayein — ye normal hai.
clasp ne tools/ aur demo/ bhi upload kar diye .claspignore file maujood honi chahiye (zip mein aati hai), aur .clasp.json mein rootDir: "apps-script" hona chahiye.
ECONNREFUSED / network error Internet ya proxy masla. Dobara chalayein; proxy ho to npm config set proxy http://… set karein.

Hissa 10 — Ek nazar mein poora tareeqa

cd C:\Users\AapKaNaam\Downloads\haseeb-autos
clasp push
clasp deploy -d "APNI-DEPLOYMENT-ID"
:: bas — phone par app refresh karein
Pehli dafa sirf: Node.js install → npm i -g @google/clasp → clasp login → Script ID → .clasp.json. Us ke baad hamesha sirf push + deploy.
