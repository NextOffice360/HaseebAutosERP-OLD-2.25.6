📘 clasp se Deploy Karna

Windows 10 ke liye — bilkul shuru se, har qadam ke sath.

👋 Pehle ye parh lein (2 minute)

Ye guide us shakhs ke liye hai jis ne kabhi clasp istemal nahi kiya aur command line (kali screen) se waaqif nahi. Sab kuch likha hai — andaza mat lagayein.

Waqt: lagbhag 25–35 minute  ·  Mushkil: bilkul aasan

Agar kahin atak jayein to aakhir mein "Masle aur un ka hal" dekhein — 99% masle wahan hal hain.

🎯 Hum kar kya rahe hain?

Aap ke paas ek dukaan ka software hai (Haseeb Autos) jo files ki shakal mein aap ke computer par pada hai. Ab wo Google ke server par chahni hain, taake mobile aur computer dono se — internet par — khul sakein.

clasp = wo truck jo aap ke computer se Google tak code le jata hai.

🧰 Hisa 1 — Tayyari (3 cheezein)

1.1 — Apna folder banayein

  1. Desktop par Right click → New → Folder
  2. Naam likhein: HaseebAutos (bina space ke)
  3. Is folder ko khol kar rakh dein — baar baar kaam aaye ga

1.2 — Zip file is folder mein khol dein

  1. haseeb-autos-v2.6.0.zip ko is folder mein copy karein
  2. Us par Right click → Extract All… → Extract
  3. Ab andar apps-script naam ka folder nazar aaye ga
✔ Check karein

apps-script folder kholein — andar bahut si .gs aur .html files hon. Agar hain to theek hai.

💡 Ahem — apna raasta (path) yaad rakhein

Masalan: C:\Users\Haseeb\Desktop\HaseebAutos\apps-script
Aage har baar isi ki zaroorat padegi.

1.3 — Google account

Jis Google account se aap Gmail / Drive chalate hain — wahi istemal hoga. Email aur password tayyar rakhein.

⬇ Hisa 2 — Node.js install karna

clasp ko chalane ke liye Node.js chahiye. Ye ek chota program hai jo computer par commands chalata hai.

2.1 — Download

  1. Browser (Chrome ya Edge) kholein
  2. Jayein: https://nodejs.org
  3. Do sabz (green) buttons nazar aayenge — 👉 LTS wala dabayein
    (jis par likha ho "Recommended For Most Users")
  4. File download hogi: node-v20.xx.x-x64.msi
LTS kyun?

LTS = Long Term Support — sab se stable wala. Hamesha LTS chunein, "Current" nahi.

2.2 — Install

  1. Download hui file par Double click
  2. "Welcome" → Next
  3. License → I accept → Next
  4. "Destination Folder" → kuch na badlein → Next
  5. "Custom Setup" → kuch na badlein → Next
  6. "Tools for Native Modules" → box ko UN-CHECK rehne dein → Next
  7. Install dabayein
  8. Windows pooche "Allow this app to make changes?" → Yes
  9. Intezaar karein (1–2 minute) → Finish
🔴 Zaroori — computer Restart karein

Install ke baad computer ko ek baar Restart kar lein. Is se aage ke aadhe masle khud hi khatam ho jate hain.

2.3 — Check karein ke Node theek laga

Keyboard par Windows dabayein, type karein cmd, phir Command Prompt kholein.

:: ye likhein aur Enter dabayein
node --version

:: jawab aisa aana chahiye:
v20.11.0

Phir ye likhein:

npm --version

:: jawab:
10.2.4
✔ Agar v se shuru number aaye

To Node theek install ho gaya. Agla qadam.

❌ Agar "node is not recognized" aaye

Command Prompt band kar ke dobara kholein. Phir bhi na chalay to computer Restart karein.

📦 Hisa 3 — clasp install karna

Ab hum truck (clasp) install karen ge.

npm install -g @google/clasp
⏳ Kya hoga?

Screen par kuch lines tezi se chalengi. 30 second se 2 minute lag sakte hain.
Kuch mat dabayein — bas intezaar karein.
Jab wapas C:\Users\...> nazar aaye, to ho gaya.

Lal (red) likhayi de to ghabrayein nahi

Aksar sirf "warning" hoti hai — masla nahi. Neeche check karein:

clasp --version

:: jawab:
2.4.2
🎉 Agar number aaye

clasp tayyar hai!

❌ "clasp is not recognized"?
npm install -g @google/clasp --force

Phir Command Prompt band kar ke dobara kholein.

🔑 Hisa 4 — Google ko ijazat dena (sab se ahem)

Ye 2 kaam hain. Bina in ke aage kuch nahi chalega.

4.1 — Apps Script API ON karein ⚡

  1. Browser mein jayein: https://script.google.com/home/usersettings
  2. Login karein (apna Google account)
  3. Neeche "Google Apps Script API" likha hoga
  4. Us ke aage wala switch ON kar dein (neela ho jaye)
🔴 Ye sab se badi wajah hai

Jab log kehte hain "clasp login kaam nahi kar raha" — to 9 mein se 10 baar yahi wajah hoti hai. Bina is ke aage kuch nahi chalega.

4.2 — clasp ko login karayein

clasp login

Kya hoga:

  1. Browser khul jaye ga
  2. Google pooche ga: "clasp wants to access your account"
  3. Allow / Continue dabayein
  4. Ek lamba code aa sakta hai — usay copy karein
  5. Wapas Command Prompt mein paste kar ke Enter dabayein
⌨ Paste kaise karein

Command Prompt mein Ctrl+V kaam nahi karta!
Right-click karein → paste ho jaye ga.

:: aakhir mein ye nazar aaye:
Logged in! You may close this page.
🎉 Login ho gaya

Ab se dobara login karne ki zaroorat nahi.

🆕 Hisa 5 — Google par naya project banana

5.1 — Naya project

  1. Browser mein jayein: https://script.google.com
  2. Upar baen taraf ＋ New project dabayein
  3. Project khul jaye ga
  4. Upar "Untitled project" par click karein
  5. Naam likhein Haseeb Autos → Rename

5.2 — Script ID copy karein 🔑

  1. Baen taraf neeche ⚙ (gear icon — "Project Settings") par click karein
  2. "Script ID" likha hoga, us ke neeche lamba code
  3. Us ke daen taraf copy wala button dabayein
:: kuch aisa lagega:
1a2B3c4D5e6F7g8H9i0JkLmNoPqRsTuVwXyZ_abc123xyz
💡 Isay mehfooz kar lein

Notepad mein paste kar ke save kar lein. Baar baar kaam aaye ga.
Ye aap ki dukaan ki chaabi hai.

🔗 Hisa 6 — Folder ko project se jodna

6.1 — Command Prompt ko sahi jagah le jayein

Pehle apna raasta (path) copy karein:

  • File Explorer mein apps-script folder kholein
  • Upar address bar par click karein (raasta neela ho jaye)
  • Ctrl + C dabayein

Ab Command Prompt mein likhein cd aur ek space, phir Right-click (paste):

cd C:\Users\Haseeb\Desktop\HaseebAutos\apps-script

Check karein — dir likhein:

dir

:: in files ka nazar aana zaroori hai:
Code.gs   Sales.gs   Index.html   appsscript.json …
✔ Agar upar wali files nazar aayein

To aap sahi jagah hain.

6.2 — .clasp.json file banayein

Command Prompt mein bilkul waise hi likhein:

notepad .clasp.json

Notepad khul jaye ga. Poochay "Do you want to create a new file?" → Yes.

Ab bilkul ye likhein (apna Script ID lagayein):

{
  "scriptId": "YAHA_APNA_SCRIPT_ID",
  "rootDir": ""
}

Misaal (example):

{
  "scriptId": "1a2B3c4D5e6F7g8H9i0JkLmNoPqRsTuVwXyZ_abc123xyz",
  "rootDir": ""
}
🔴 Gaur karein

rootDir ko khali rehne dein (""), kyun ke hum pehle hi apps-script folder ke andar hain.

Save: Ctrl + S → Notepad band kar dein.

type .clasp.json

:: jo abhi likha tha wo nazar aaye to ✔ jod lag gaya

🚀 Hisa 7 — Code bhejna (clasp push)

clasp push
└─ appsscript.json
Pushed 81 files.
🎉 Mubarak ho!

Code Google par pahunch gaya.

⚠ Agar ye poochay
? Manifest file has been updated. Do you want to push and overwrite? (y/N)

y likh kar Enter dabayein.

Check: browser mein script.google.com kholein — baen taraf apni sari files nazar aayengi.

🏗 Hisa 8 — Pehli dafa Setup (database banana)

Ab Excel jaisi sheets banani hain. Ye sirf ek dafa hota hai.

8.1 — Spreadsheet jodna

  1. script.google.com par apna project kholein
  2. Upar function ke dropdown mein attachSpreadsheet chunein
  3. Run (▶) dabayein
  4. "Authorization required" → Review Permissions
  5. Apna Google account chunein
  6. "Google hasn't verified this app" aaye ga — neeche dekhein 👇
😰 "Google hasn't verified this app" — ghabrayein mat!

Ye aap ka apna code hai jo aap ne abhi upload kiya — koi bahar wala nahi.

  1. Advanced par click karein (chhota, neeche baen taraf)
  2. "Go to Haseeb Autos (unsafe)" par click karein
  3. Allow dabayein

8.2 — Sari sheets banayein

  1. Function dropdown mein setupAll chunein
  2. Run dabayein
  3. 10–30 second intezaar karein
  4. Neeche "Execution log" mein lambi list aaye gi (sab sheets ke naam)
🎉 Database ban gaya!

8.3 — Demo data (ikhtiyari)

Test ke liye seedDemo chala sakte hain.

⚠ Asli kaam ke liye

seedDemo mat chalayein. Ye sirf test data hai. Asli products aap ERP ke andar CSV se import karen ge.

🚪 Hisa 9 — Deploy (dukaan ka darwaza kholna)

9.1 — Naya deployment

  1. Upar daen taraf "Deploy" (neela button) dabayein
  2. "New deployment" chunein
  3. Gear ⚙ ke aage "Select type" → Web app
  4. Neeche settings bharein:
SettingKya chunein
DescriptionHaseeb Autos v2.6 (jo marzi)
Execute asMe (apna email)
Who has accessneeche dekhein 👇
🔐 "Who has access" — kaunsa chunein?
  • Anyone with Google account → sirf aap aur aap ka staff (har kisi ko Gmail chahiye) — behtar aur mehfooz ✅
  • Anyone → koi bhi, bina login (sab se khula, kam mehfooz)
  1. Deploy dabayein
  2. Authorization poochay to Allow (Hisa 8.1 ki tarah)

9.2 — URL copy karein 🔗 (sab se qeemti cheez)

https://script.google.com/macros/s/AKfycb……………/exec
🎉🎉 Ye aap ki poori ERP app ka pata hai!

Isay copy kar ke Notepad mein save kar lein.

🔄 Hisa 11 — Rozana update kaise karein

Jab bhi code badle (naya version aaye), sirf:

cd C:\Users\Haseeb\Desktop\HaseebAutos\apps-script
clasp push

Phir: Deploy → Manage deployments → Edit (pencil) → Version: New version → Deploy

💡 Shortcut

clasp push ke baad clasp deploy likhein — naya version ban jaye ga. (Magar pehli dafa UI se karein taake samajh aaye.)
