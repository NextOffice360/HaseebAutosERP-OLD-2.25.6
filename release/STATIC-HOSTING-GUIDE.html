🌐 Static Hosting Guide

Netlify · Vercel · GitHub Pages · Firebase — Windows 10, bilkul shuru se.

⚠ Sab se pehle ye samajh lein (bahut zaroori)

Aap ka ERP do hisso mein banta hai:

① Frontend = jo nazar aata hai (buttons, screens) → Static host par ja sakta hai ✅

② Backend = database (Google Sheets) → hamesha Google Apps Script par rahega 🔒

Is guide mein hum frontend ko Netlify (ya kisi aur) par rakh kar usay Google ke backend se jodte hain. Database move nahi hota.

🚫 Jo NAHI ho sakta

Google Sheets ko Netlify par host nahi kar sakte. Sheets hamesha Google ke paas rahengi. Static host sirf screen deta hai — data nahi.

🎯 Teen raaste — kaunsa chunein?

A) Demo sirf 👀

Sab se aasan. Mock data, koi login nahi, koi backend nahi.

Kab: kisi ko dikhana hai, ya training.

B) Asli app 🚀

Behtareen. Screen Netlify par (fast + custom domain), data Google Sheets mein.

Kab: rozana ka kaam.

C) Sirf Google ⚙

Kuch host nahi karna. script.google.com se hi chalao.

Kab: sab se kam jhanjhat.

💡 Mera mashwara

Agar aap beginner hain → pehle C se shuru karein (clasp guide). Jab sab theek chalne lage, phir B karein.

📦 Hisa 1 — Tayyari

1.1 — Backend pehle deploy karein

Static hosting se pehle aap ka Apps Script backend chal raha hona chahiye.

Agar abhi tak nahi kiya

Pehle CLASP-GUIDE-WINDOWS.html follow karein (Hisa 1–9). Aakhir mein jo .../exec wala URL milega — wahi yahan kaam aaye ga.

Wo URL kuch aisa hota hai:

https://script.google.com/macros/s/AKfycb……………/exec

1.2 — Python chahiye (static build ke liye)

  1. Jayein: https://www.python.org/downloads/
  2. Bada "Download Python 3.x.x" button dabayein
  3. Installer chalayein
  4. 🔴 "Add Python to PATH" wala box ZAROOR tick karein (neeche)
  5. Install Now → intezaar → Close
🔴 Sab se aam ghalti

"Add Python to PATH" tick karna bhool jana. Bina is ke python command kaam nahi karega.

Check karein (Command Prompt):

python --version

:: jawab:
Python 3.12.0

🅱 Raasta B — Asli app (screen Netlify, data Google)

Yahan hum ek khaas build banayenge jo Google ke backend se baat kare.

🧠 Ye kaise kaam karta hai?

Netlify wali screen aap ke Google backend ko JSONP ke zariye sawal bhejti hai: .../exec?t=jsonp&a=items.list — aur Google jawab deta hai. Is liye screen kahin bhi ho, data hamesha aap ki Google Sheet mein rehta hai.

1

Command Prompt kholein, apne folder mein jayein:

cd C:\Users\Haseeb\Desktop\HaseebAutos
2

Static build banayein (apna /exec URL lagayein):

python tools\build_static.py "https://script.google.com/macros/s/AKfycb……/exec"

Kya hoga:

✔ Built dist-static/index.html (900.4 KB)
✔ Built dist-static/manifest.webmanifest + sw.js + icons (PWA)
✔ Saved static-config.json
✔ Yaad rakhein

URL ek hi dafa poochna parta hai. Agli dafa sirf python tools\build_static.py chalayein.

3

Jayein: https://app.netlify.com/drop

4

dist-static folder ko kheench kar chhor dein

5

Link milega → kholein → login karein (wahi username/password jo ERP ka hai)

🎉 Ab aap ki app Netlify par hai — aur data Google Sheets mein!

🔁 Naya version kaise chadhayein

Jab bhi backend badle (naya version):

cd C:\Users\Haseeb\Desktop\HaseebAutos

cd apps-script

cd ..

🌍 Doosre hosts (ek hi folder, alag jagah)

HostKaiseKhayal
Netlify ⭐ app.netlify.com/drop → folder drop Sab se aasan. Free. Custom domain muft (SSL ke sath).
Vercel vercel.com → Add New → Project → folder drop Tez. GitHub se judta hai.
GitHub Pages GitHub repo banayein → Settings → Pages → folder chunein Muft, magar thoda technical.
Firebase Hosting firebase init → firebase deploy Google ka apna — Apps Script ke sath acha.
Cloudflare Pages pages.cloudflare.com → Upload assets Bahut tez CDN.
⚠ Ek hi shart

Har host par dist-static folder ka andar ka content jana chahiye — folder khud nahi. Yani index.html sab se upar nazar aaye.

🏷 Apna domain lagana (ikhtiyari)

Netlify par:

  1. Apni site kholein → Domain settings
  2. Add custom domain
  3. Apna domain likhein (masalan haseebautos.com)
  4. Netlify aap ko 2 addresses dega (DNS records)
  5. Apne domain wali site (GoDaddy / Namecheap) par ja kar ye records dal dein
  6. 1–24 ghante intezaar → SSL (https) apne aap lag jaye ga

🆘 Masle aur un ka hal

MaslaWajahHal
python is not recognized Python install nahi hua ya PATH nahi laga Python dobara install karein — "Add to PATH" tick karein → Restart
Build ke waqt ✖ Apps Script ka /exec URL chahiye URL nahi diya URL quote " " ke andar likhein
Screen khulti hai, magar data nahi aata Purana deployment Apps Script → Deploy → Manage → New version → phir build dobara
"Network error" ya blank screen Ghalat URL, ya deploy nahi hua .../exec URL browser mein kholein — app khulni chahiye
Login ke baad "Session expire" baar baar Backend ne token reject kiya Deploy Execute as: Me + Anyone check karein
Bada kaam (CSV import) fail JSONP sirf GET hai (~2 KB limit) Bada kaam Google wale URL (.../exec) par kar lein
PWA install nahi hoti http (https nahi) Netlify/Vercel https dete hain — wahan se kholein
📏 JSONP ki had (honest)

JSONP sirf GET hai, is liye payload ~2 KB tak theek hai. Rozana ke kaam (sale, stock, reports) is mein aate hain. CSV import jaisa bada kaam Google wale .../exec URL par karein.
