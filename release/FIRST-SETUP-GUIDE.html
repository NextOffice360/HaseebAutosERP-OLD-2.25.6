0. Sab se pehle ye baat samajh lein

Apps Script editor mein aap file select nahi karte — aap function select karte hain. File apne aap khul jati hai. Is liye confusion hoti hai ke "file kaun si?". Jawab: function chunein, file ka fikr chhorein.

EDITOR KA NQSHA (screen par kahan kya hai)
Bayen taraf Files ki list — Code.gs, Setup.gs, Sales.gs …
Upar (toolbar) Ek dropdown jisme likha hota hai "Select function" — isi se function chuna jata hai
Dropdown ke bagal ▶ Run button (aur wrench 🔧 Debug)
Neeche Execution log — natija yahan likha aata hai
⚠ Bahut zaroori
Dropdown mein sirf wahi functions nazar aate hain jo file mein seedhe (top-level) likhe hote hain, yani function setupAll(). Setup.setupAll() jese (jiske beech mein dot hai) dropdown mein kabhi nahi aate — unhen Run nahi kiya ja sakta.

Ye poori table yaad rakhne ki zaroorat nahi — sirf apna kaam dhoondhein aur woh function chalayein.
